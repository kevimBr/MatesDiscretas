Justificación de la ImplementaciónPara este proyecto, decidimos implementar el tipo de dato NTree utilizando una lista de árboles ([NTree a]) para representar los hijos de cada nodo.data NTree a = Node a [NTree a]Elegimos esta estructura recursiva porque elimina la restricción binaria de tener exactamente dos espacios (izquierdo y derecho). Al usar una lista:Un nodo hoja simplemente tiene una lista vacía [].Un nodo puede tener cualquier cantidad de hijos ($0, 1, \dots, n$).No es necesario un constructor Void explícito como en los árboles binarios, ya que la ausencia de hijos se maneja con la lista vacía.Adicionalmente, implementamos nuestras propias funciones auxiliares (OurMap, OurSuma, etc.) para manejar la recursión sobre estas listas de hijos sin depender de las funciones predefinidas de Haskell, cumpliendo con los requisitos del proyecto.
